## 2. Cross-Layer Duplication & Contract Drift Summary

1. **Product Category Enum Duplicated Without Shared Runtime Package**:
   - Even though `udyam-pay-frontend/package.json` declares `"udyam-pay-backend": "file:../udhyam-pay-backend"`, frontend never imports from it (`schemas.ts`, `status-meta.ts`, `types/api.ts`, and `fixture-schema.ts` duplicate `ProductCategory`, `UserRole`, `ApplicationStatus`, and validation regexes independently).
2. **Phone Masking Security Drift**:
   - Backend logger (`src/config/logger.ts`) carefully redacts `phone`, `email`, and `fullName`, and frontend provides `maskPhone` (`src/lib/utils.ts:21`). However, `maskPhone` has `0` callers in UI while `MerchantApplicationDetailPage.tsx:222` and `AdminApplicationsPage.tsx:138` display full unmasked customer phone numbers.
3. **RBAC Drift Across Backend vs Frontend**:
   - Frontend `guards.tsx` and `admin.routes.ts` treat `ADMIN`, `SYSTEM_ADMIN`, and `OPS_AGENT` uniformly as platform operators (`isAdminRole`).
   - Backend `application.routes.ts:62,69,88` and `offer.routes.ts:31` still check only `'ADMIN'`, causing `SYSTEM_ADMIN` and `OPS_AGENT` tokens to be treated as merchant-scoped or logged as `MERCHANT_USER` (`403` / wrong `actorType`).
4. **Pagination Metadata Drift**:
   - Backend `common/pagination.ts` exports `buildPaginationMeta()` (returning `{ page, pageSize, total, totalPages }`), yet routes manually construct `{ page, pageSize, total }` without `totalPages`. Frontend recalculates `totalPages = Math.ceil(total / pageSize)` client-side (`MerchantApplicationsPage`, `MerchantPurchasesPage`).
5. **BigInt / JSON Serialization Drift**:
   - `sendSuccess` (`response.ts`) already recursively converts `bigint` → `string`. Manual object spreading in `offer.routes.ts` and `application.routes.ts` creates `null` vs omitted (`undefined`) differences across endpoints, while `PUT /api/v1/admin/lenders/:id/config` omits Zod parsing altogether, forcing the frontend (`AdminLendersPage`) to exclude `minAmountPaise` and `maxAmountPaise` from edits.
6. **QR Generation Package Mismatch**:
   - Backend depends on unused `qrcode` + `@types/qrcode` in `package.json`, whereas actual SVG QR rendering lives cleanly on the frontend via `qrcode.react` (`QrTicketCard.tsx`).
